Deploying the Service

Deployment starts with a build. The build compiles every package and then bundles the server so it can run anywhere. This paragraph is long enough for the article extraction to keep it as the main content of the page.

After the build, copy the bundle to the host and start it. Check the health endpoint to confirm that the service answers requests before you send any traffic to it.

Rollback

If the health check fails, restore the previous bundle and restart the service. Keep at least two bundles on the host so a rollback is always possible without a new build.
